# DIYWOODPLANNER

Professional woodworking plan production inside Codex. No standalone application,
server or user interface.

- **Original Alderline X4 P1:** immutable files in
  [`deliverables/DIYWOODPLANNER_Alderline_X4`](deliverables/DIYWOODPLANNER_Alderline_X4/).
- **Development workflow, new source and regression examples:**
  [`production/README.md`](production/README.md).
- **Audit and architecture:** [`production/docs`](production/docs/).
- **Project Codex Skill:**
  [woodworking-plan-production](.agents/skills/woodworking-plan-production/SKILL.md).

Only one furniture structure, at two widths, has been exercised. The workflow is
not yet generalized across different woodworking products. Digital validation is
not structural safety evidence or a safe-working-load certification.
