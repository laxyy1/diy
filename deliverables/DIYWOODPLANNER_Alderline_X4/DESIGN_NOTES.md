# Design decisions — Alderline X4 / P1

The supplied reference images show a tall freestanding storage form, four shelves under a separate cap, four corner posts, repeated side Xs, horizontal side rails and an open front. Only these visible relationships informed this product. No unseen dimensions or fastener capacities were inferred from a photograph. The supplied publication's text, drawings and graphic layout are not reproduced.

The independently established geometry uses a 900 × 350 frame, 1782 posts, four 18 mm plywood shelves on inward cleats, a 920 × 370 top, and 18 × 35 exterior half-lapped side X slats. Exterior slats make maximum width 936. Independent rear steel X straps add bracing across the otherwise open back, and two manufacturer-selected wall restraints are mandatory before loading. These are explicit new design features rather than assumptions about the reference object.

The top and shelves use plywood to avoid a solid-board tabletop movement detail. Front/rear aprons sit between posts; side rails have dowel joints into posts. A shelf has 0.5 mm clearance to each side frame and is supported over 29.5 × 260 mm per side. The paired Xs all use identical 400 mm end-plane spacing; their horizontal cut planes and true 35 mm slat width define the miter mathematically. Their 447.588 mm long-edge length is distinct from the 465.161 mm projected extremity length. This distinction is documented to avoid incorrectly sizing the blanks.

The screw schedule was reviewed for opposing fastener collisions: initial candidate cleat screw lines near the X end screws were discarded. Final cleat stations are y=110/175/240 rather than the X screw centre lines near y=84.62/265.38. The exported CAD bores are checked with 48 independently placed nominal dowel cylinders.

Metric dimensions control; there is no rounded imperial cutting schedule. Physical stock must match the final modeled dimensions. Parameter changes require revalidation and a new narrative/drawing review; the PDF builder intentionally refuses altered P1 parameters to prevent stale instructions. The canonical model, parameter file, derived dimensions, cut list and selected read-back checks are provided for independent review.

This package has no physical prototype evidence. Supplier material data, actual hardware specifications, wall construction, glue preparation and physical strength/stability testing remain unresolved. No safe working load, fastener capacity or commercial release certification is stated.
